# 옆집공방 (Yeopjip Workshop)

우리 동네 공방 전문가와 소비자를 연결하는 모바일 우선 장인 플랫폼입니다.

## 핵심 가치
- 사진으로 제작·수선 의뢰
- 지역 기반 공방 탐색
- 바로 주문 또는 장인 견적 제안
- 직접 방문 / 공방 왕복배달
- 제작·수선 진행상태 확인
- 8단계 장인별 신뢰 시스템

## 기술 스택
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Supabase 예정: Auth / PostgreSQL / Storage / Realtime

## 실행
```bash
npm install
npm run dev
```

## MVP 개발 순서
1. 모바일 홈 및 공방 탐색
2. 소비자/장인 인증과 역할 분리
3. 공방 프로필과 서비스 메뉴
4. 사진 의뢰 및 견적
5. 채팅
6. 주문/작업 상태
7. 직접 방문 및 왕복배달
8. 후기와 장인별
9. 관리자
10. AI 사진 분류와 추천
