# 옆집공방 제품 기준선 v0.1

## 한 문장
우리 동네의 장인과 소비자를 연결해 제작, 수선, 복원, 리폼, 클래스까지 발견·의뢰·전달·작업·수령을 이어주는 모바일 플랫폼.

## 핵심 UX
- 정형 작업: 공방 서비스 메뉴에서 바로 선택
- 비정형 작업: 사진을 올리고 주변 장인에게 견적 요청
- 전달: 직접 방문 / 공방 왕복배달 / 향후 택배
- 신뢰: 8단계 장인별 + 인증 + 실제 거래 기반 후기

## MVP 화면
- `/` 소비자 홈
- `/workshops` 공방 탐색
- `/workshop` 공방 상세
- `/request` 제작·수선 의뢰
- `/delivery` 왕복배달 진행
- `/artisan` 장인센터

## 이후 화면
로그인/가입, 채팅, 견적 비교, 주문 상세, 작업 타임라인, 리뷰, MY, 관리자.
