## 현재 판단
핵심 거래 루프(가입 → 공방 등록/탐색 → 사진 의뢰 → 견적 → 작업상태 → 완료 → 후기)는 코드와 DB 기준으로 MVP 구조가 완성됐다. 지도, 결제, 실제 배송, 알림처럼 외부 사업자 키/계약이 필요한 기능은 출시 통합 단계로 분리한다.
